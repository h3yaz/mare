O teu código de segurança

Como o armazenamento automático está com um problema neste ambiente, guarda este código nas Notas do telemóvel: toca no campo abaixo, mantém pressionado para selecionar tudo, e escolhe "copiar". Cola-o depois nas Notas. Se os dados se perderem, cola-o de volta no campo "restaurar" acima.
Isto é conhecimento geral sobre o ciclo — o dela pode não seguir este padrão à risca. A fonte mais fiável é sempre ela própria; usa isto como mapa, não como manual.
